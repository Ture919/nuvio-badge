# Badge per Nuvio (copia corretta)

Regole dei badge delle fonti per **Nuvio** (Nuvio Desktop 0.1.38: Impostazioni → Flussi → sezione "STILE FUSION" → "URL badge Fusion" → incolla l'URL → "Importa"; poi tocca la riga nuova per renderla "Attivo").

Origine: regole condivise su pastebin `aR5uAwma`, immagini del pacchetto
[djgenesis/stream](https://github.com/djgenesis/stream) (le immagini restano collegate all'originale).

File da importare:

```
https://raw.githubusercontent.com/Ture919/nuvio-badge/main/badge_ture.json
```

## Correzioni rispetto all'originale (23/11/2026)

1. **WebDL**: non scatta più sulla scritta "Web Link" (usata da AIOStreams/Prism per i link diretti).
2. **DD+**: ora riconosce anche "DD+" seguito da spazio (prima non scattava mai in quel caso).
3. **4K**: non scatta più su "UHD BluRay" quando il file è 1080p (es. "1080p UHD BluRay"); "2160p" resta 4K.
